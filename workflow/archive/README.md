# Archive

**Nothing in this directory is current. Nothing in it is authority.**

These files record how the project worked and what was investigated between 2026-08-15 and
2026-08-22. They are kept because they contain real measurements, real evidence, and the
reasoning behind decisions that are still in force.

**Do not read anything here for project state.** Every number in here is a snapshot of a
moment that has passed. Current state lives in:

```
workflow/MASTER.md        project state
workflow/BLOCKS.md        structure, roles, rules
workflow/SKILLS.md        method
workflow/CONTEXT.md       shared orientation
workflow/DECISION_LEDGER.md   the decisions that are in force
workflow/blocks/          each block's own state, spec, review, handoff, evidence
```

**Do not read anything here for method.** The task-card process it describes was replaced by
the block structure. Its rules survive only where `BLOCKS.md` restates them.

Read here only to answer *"why was that decided, and on what evidence?"* — and then cite the
decision in `DECISION_LEDGER.md`, not the file here.

Evidence that is still load-bearing was **moved out** of here, into
`workflow/blocks/<BLOCK>/evidence/`. If a file here contradicts one there, the one there wins.
